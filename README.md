# Python-Based Keylogger

## Project Overview

This project explores the development and implementation of a Python-based keylogging system for educational purposes and cybersecurity research. It focuses on keystroke monitoring, activity logging, and file-based storage, along with Windows-specific execution and automation components.

**Disclaimer:** This project is intended strictly for authorized security research, controlled laboratory environments, and educational purposes. It must not be used to monitor individuals or capture sensitive information without their explicit consent.
